# 关键字库驱动通道识别 · V0.6

## 输入依据

关键字与排除词来自用户提供的截图可见部分。重复和大小写形式归一处理；截断、不可见的尾部文字未猜补。另补全Temperature完整拼写、StdDev/标准差等常见统计量拼写、最大/最小中文后缀，并增加采样间隔10min的消歧。完整可导出的程序词库在`gui/channel-library.js`，词库版本1.0.0；界面“通道关键字库与排除规则”可查看和下载JSON。词库是独立版本化数据，不执行用户正则或外部脚本。

## 识别维度

每一原始列产生独立记录：列序号、原列名、参数类型、统计量、高度、高度来源、传感器标识、原单位、标准单位、换算系数、命中关键字、排除词、状态、依据及人工覆盖标记。风速/风向、温度、气压、湿度、电压分别按高度保留；平均、标准差、最大、最小不互相覆盖。

时间与QC标记在上方字段映射中单独处理，不要求在风参数分类表里作为风参数。U/V是数据源适配的分量类型，优先于电压短字母v；单独的V或V 10m按电压候选识别，不将其擅自与U配对。

## 规则次序

1. Unicode兼容形式、摄氏符号及大小写归一，拆分常见CamelCase，同时保护hPa/kPa等单位。
2. 提取显式米制高度；紧凑通道名和文件名高度只标为推断依据；通道号不等同高度。多个不同高度出现在同一表头时保留待确认。
3. 按要素关键字命中，排除关键词优先。短英文词按词/数字边界匹配，避免sp、pr、v、hr等在长单词内误命中。
4. 统计量另行识别：明确标准差/最大/最小/阵风优先；已识别要素但无统计量后缀时为均值候选。10min是采样间隔，不视作Min。
5. 只有均值风速进入概览通道；风向同样只配均值。相同高度多均值/多风向不静默选定，要求人工选择。
6. 风速标准差/极值按高度及传感器标识配对；同高度多候选而无法唯一配对时不绑定。Pressure/Temperature的标准差仍属于气压/温度，不作为风速标准差。
7. 纯SD/STD列识别为标准差但不猜其要素，留待人工确认。仅单位证据的列也明确提示核对。

## 截图排除规则的执行

- 垂直、Z方向、VWindSpeed、TI等不进入水平平均风速。
- ℃/°C/degree C等不作为风向证据；温度通道若仅由单位识别，显示待确认。
- Inner Temperature、Int Temp、PTemp不作为外界温度。
- 可靠性、有效率、Reliability、Data Availability的百分比不当作相对湿度。
- 按用户表，Voltage Avg/STDev/Deviation/Valid/Level等命中电压排除词时不自动提取为电压通道。此处尊重原关键字库，不擅自放宽；若实际设备确实如此命名，可人工确认并保留审计标记。
- gust不归入均值。最大/最小冲突或多个要素同时命中不自动选取。

## 数值保留与单位

现有`rows[].values[]`继续服务风速概览，增加可配对的stddev、maximum、minimum。`parameterChannels`保留温度、气压、湿度、电压的列定义，`rows[].parameters`按该顺序保留数值；`catalog`保留全部列（含排除/未知项）及识别依据。

明确单位才转换：°C→K（标准差不加273.15）、hPa/mb→Pa、kPa→Pa、百分比→0—1比例、明确速度单位→m/s。单位未提供时保持原数值并在schema标为单位待确认，不凭数值范围猜测物理单位。当前风速导入面板仍要求用户确认默认m/s或显式选择其他单位。

参数识别及数值提取不等于完成空气密度、湍流或极端风速工程计算，本轮没有启用这些专业计算或判级。

## 人工修正与扩展

导入预览逐列展开，可修改要素、统计量及高度。修改后立即更新候选均值通道数；实际提交采用修正后的schema。若人工强制改写排除结果，保留原命中/排除证据和manual标志。切换工作表会清除基于旧列序号的修正，防止错列。

`ChannelLibrary.identify(headers, filename, overrides)`返回全列schema，`group()`按要素/高度/传感器分组。`WindData.detect`将该schema转成原有导入接口，不再维护另一套相互矛盾的风速匹配正则。旧单文件兼容预检不参与四阶段真实识别链，建议使用顶部多文件入口。

## 验证与边界

已验证短词误判、全部要素类别、排除词、无后缀均值、采样间隔、大小写/单位、不同高度、不同传感器、标准差配对、参数SI换算、手动覆盖审计，以及错误选择Max列时阻断。四阶段CSV、XLSX及长期窗口仍通过回归。

实际设备的安装报告、厂家通道编号和缺失高度关系不能单靠关键字还原；用户实际文件尚未提供，本轮不声称已验证所有厂家格式。JSON词库可导出，尚未开放任意JSON导入或跨设备同步自定义规则。
