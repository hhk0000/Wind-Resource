# 数据输入、识别与真实概览 · V0.5

本轮开发范围：四阶段文件分别保留、候选识别与人工修正、时间/通道/标记校验、最终测风年锚定、10/20/30年中尺度窗口，以及A测风概览的真实统计与绘图。B/C/D专业参数引擎仍未接入。当前对话未收到用户所述测风文件，因此只完成生成测试集与软件行为验证，实际样本适配待附件到达后继续。

## 使用路径

1. 数据管理→“真实多文件识别与测风概览”，一次选原始、QC、最终轮毂、中尺度四类文件；也可分批导入。
2. 核对项目显示时区、每份文件文本所属时区、日期格式、阶段、工作表和字段。文件名识别只是候选，未识别阶段不自动当原始数据。
3. 识别全部含高度风速通道；无标高时输入高度，同高有多个候选通道时手动选择，禁止自动挑一个当正确值。支持风速/风向、ERA5 U/V；不支持把多个经纬度格点混为一条序列。
4. 核对有效QC标记值及风速单位。无QC列只作风速数值有效性检查，不自动执行工程质量控制；有QC列时仅用户确认的有效值生效。
5. 确认后进入真实概览。可选择高度、日均/小时聚合、曲线开关及中尺度窗口。部分阶段缺资料时显示缺项，不调用合成值补齐。

## 文件支持

- CSV/TXT：UTF-8（含BOM）、GB18030，逗号/分号/制表符，前60行内查找候选表头，支持引号及引号内分隔符。
- XLSX：选择工作表，处理共享/内联字符串与数值日期，仅使用公式缓存值，不执行公式。自带ZIP目录、CRC和解压长度检查；不接受加密、宏、ZIP64、外部工作表或DTD实体。
- XLS、NetCDF、GRIB、多个格点混合导出、无可靠表头的专有测风格式暂不支持，需转换或依据实际样本增加适配器。
- 单文件上限50 MiB、100万行；XLSX有解压大小/比例和列数限制。当前实现运行于浏览器内存，刷新后重新选择文件，不上传云端。
- 时间支持年优先日期、ISO时区、明确指定的日/月优先日期、Excel序列、Unix秒/毫秒，支持日期与时间两列。无时区文本不猜测为UTC：在页面确认；含UTC的时间列标题会给UTC候选。
- 风速通道示例：WS_80m、wind_speed_125m；方向示例：WD_80m、wind_direction_125m；ERA5分量示例：u100、v100。其他列名可手动指定。方向来源高度和风速高度不同时在来源标签中保留提示。

## 时间与数据诊断

记录按时刻排序，重复时刻保留首条并计数；错误日期、列数异常计入诊断。采样步长取相邻正时间差的众数，不在该网格的记录阻断本批导入，避免悄悄混用时距。无效风速/QC标记保留为缺口，不插值。

时戳当前按观测所在时间格起点处理，文件范围为[首条时刻, 末条时刻+推断步长)。若原始记录定义为统计区间终点，或含重复边界行，需结合采集器说明先转换/确认；实际文件到达后核对，不凭文件名推断此语义。

最终文件必须恰好具有一个日历年跨度。结构上覆盖一年与有效数据完整率分开报告：有缺测/无效记录不会被称为有效完整年。少于或多于一年时不替用户擅自裁切，不生成长期窗口。

## 中尺度窗口规则

锚点为最终文件结束时刻end（不含），窗口为[end向前N个日历年, end)，N可选10/20/30。闰日回溯遇非闰年取2月28日，年度分段边界从同一锚点逐年回溯；不把滑动完整年误称为自然年。

例如最终数据为[2024-01-01 00:00,2025-01-01 00:00)，对应：10年[2015-01-01,2025-01-01)、20年[2005-01-01,2025-01-01)、30年[1995-01-01,2025-01-01)。

每个窗口披露请求起止、有效/应有数量及覆盖率；资料范围不足、缺测或风速无效时标记为部分覆盖。年图不造缺失年份；无样本区间不连线。窗口内风向统计只使用风速>0.5m/s且方向有效样本，按气象来向16扇区归一化；这是概览口径，不是风资源合规判定。

## 测风概览绘图

- 长期中尺度：年度窗口均速、方向图、横向年份/均速表及逐年覆盖明细。
- 四阶段：原始、QC、最终轮毂、QC范围内中尺度，按同一时间轴进行小时或当地日均聚合；QC缺口不补点。日均格有部分有效记录时仍给均值，不代表该日完整。
- 中尺度限制到QC资料时间范围，不把QC已删除时刻从时间轴整体剔除。
- 各阶段显示实际高度。选择明确高度后，某阶段无该高度则显示缺项，不自动用另一层替代；“各阶段首个通道”允许比较异高序列但逐条注明。
- 时序超过1000格时按固定间隔采样显示并显式披露，表格限前366行；CSV保留完整聚合结果。当前为静态SVG概览，不包含缩放后的自适应降采样。
- 图→表→规则，SVG/CSV保留真实来源标记；真实资料不足时不自动切换合成示例。

## 保存与隔离

同批文件全部成功才提交，不因某一文件失败更新一半阶段。同阶段重新确认会替换当前内存版本；当前不提供上传文件的云端版本留存。项目切换会取消待提交结果并清空数据，避免串用。原始记录、客户文件及解析产物不提交Git。
