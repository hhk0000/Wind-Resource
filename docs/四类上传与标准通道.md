# 四类上传、人工映射与标准列名 · V0.7

## 操作流程

数据管理主入口是一张四行清单：原始数据、质控后/删除标记后数据、结果数据、中尺度数据。旧逐文件确认卡片和旧单文件预检入口已从主流程隐藏，原有读表/识别/计算函数继续复用。

### 批量上传

最多四个文件，每类一个。文件名需含对应类别，例如：原始数据.csv、质控后数据.xlsx（或删除标记后数据.txt）、结果数据.csv、中尺度数据.csv。批量选择前先校验所有名称；未知类别、多个类别同时命中或同一批类别重复时，不开始本批读取，提示改名或使用单独入口。

归类只依据确定性文件名规则，不凭位置猜四个文件的类型。存在的英文别名仅作为兼容，建议按上述中文名称使用。

### 单独上传、删除和替换

每行提供单独上传或重新上传/替换，入口直接指定类型，因此单文件不用改名。可删除一个类型后重新上传，其他类型不变。文件状态依次为读取中、待人工识别（如需）、处理中、已就绪或失败。

每个类型独立提交。替换文件只有解析和映射成功后才替换该类型的已就绪数据；失败保留旧数据及旧标准表头导出内容。不同类型可分别成功/失败，并在清单中显示，不宣称整批内容全成或全败。

删除时同时清除对应文件、schema及当前图表依赖；删除结果数据后长期窗口失去锚点，不能继续显示之前的有效窗口。删除全部真实资料后不自动用合成图冒充结果。异步读取/处理后检查任务身份，已删除、被替换或已切换项目的任务不允许迟到提交。

## 纯程序识别

流程为：文件读取 → CSV/TXT或XLSX解析 → 关键字/排除词匹配 → 要素/高度/统计量识别 → 需要时人工映射 → 数值校验 → 标准命名 → 供图表调用。

全部在浏览器本地运行，不调用AI、LLM、远程识别服务；文件也未上传云端。“已就绪”指本地处理完成，不代表云端持久化。

依据用户关键字库，规则库升级为1.1.0，增加风功率密度WPD、power density、风功率密度、W/m²等确定性别名。新规则没有从均速推算WPD：上传WPD列是输入参数，计算WPD仍需已批准的密度与统计口径。

## 何时弹出人工映射

- 时间列未识别或分列时间需指定。
- 非时间/标记/经纬度辅助列没有确定的参数类型。
- 标准差所属要素不明确，或要素/统计量冲突。
- 已识别参数缺少测量高度。
- 相同高度有多个均值风速，无法自动决定概览主通道。
- Excel有多个工作表，需明确选择。

映射窗口可指定时间/日期、独立时分秒、QC标记、文本时区、有效标记值、每列的参数类型/统计量/高度；不需要的未知列可明确“忽略”。只有信息完整后才继续本类型处理。已按排除规则忽略的字段不反复要求人工确认；时间、标记和经纬度也不强制按风参数命名。

多个未知文件按队列弹窗；可稍后处理并在文件行重新打开。修改工作表清空旧表的列序号映射，防止错列。对于多候选均值，可仅勾选一个概览主通道；未作为概览主通道的列仍在标准表头及映射导出中保留，不直接丢弃。

## 标准名称

|参数|均值列名示例|其他统计量示例|
|---|---|---|
|风速|WS-100m|WS-100m-STD、WS-100m-MAX、WS-100m-MIN|
|风向|WD-100m|WD-100m-STD|
|风功率密度|WPD-100m|WPD-100m-MAX|
|温度|TEMP-10m|TEMP-10m-MIN|
|气压|PRES-10m|PRES-10m-STD|
|湿度|RH-80m|RH-80m-MAX|
|电压|VOLT-10m|按关键字排除规则及人工确认决定是否使用|
|U/V分量|U-100m、V-100m|配对后的概览使用WS-100m|
|时间/标记|TIME、CLOCK、QC-FLAG|保持分列语义|

名称由程序生成，不让用户自由输入不一致的规范名。相同要素、高度、统计量出现多个传感器时附加CH编号或原列序号，确保不覆盖其他列。忽略列没有标准名。原始表头始终保留在mapping中，不修改用户原文件。

数据模型增加standardHeaders（包含原列名、标准名、原列号、要素、高度、统计量、单位、识别证据）、命名规则版本及关键字库版本。实际风速绘图通道的name采用标准名，originalName保留来源。

## 导出与单位

每行可下载标准列名JSON与标准表头CSV。JSON保留原始/标准映射、版本及单位；CSV只改变已映射列的名称，数值和日期单元格保持原始单位/表示，不伪称已转换为SI。标准名相同不代表原始单位相同，后续程序须读取mapping，内存中的已识别数值仍按既有单位规则转换。

CSV排除明确忽略的列。普通负数等合法数值不因公式注入保护被改成带单引号文本；危险表达式导出会加保护。标准CSV与映射JSON应配套使用，标准时间可能包含TIME和CLOCK两个原始字段。

## 验证与边界

Node检查：四种中文类别、未知/冲突文件名、WS/WD/WPD名称、统计量后缀、重复名消歧及原表头保留。

浏览器检查：四行清单、自动批量识别、任意名单独上传、删除单类并重新上传、未知字段强制映射、显式忽略、标准名实时预览、原表头/标准列下载、替换失败回退、项目隔离、概览联动和请求记录。生成数据校验中未出现外部请求。

原四阶段小时/日均数值、30年小时中尺度、三个窗口、XLSX工作表选择及归档看板也做回归。全部测试使用生成数据，不包含客户原始文件。当前仍是本地数据处理，没有云端上传资产服务、永久文件版本和其他专业参数计算引擎。
